# Overlay Lab Starter (Day 2)

West-MEC Coding, Hover Effects and Overlays.

The page layout and colors are already built. Your job: Write overlay, fade, slide, zoom, and click (:active) code.
Every spot you write in is marked with a `/* YOUR CODE */` comment in `global.css`.

## Get the code

1. Open VS Code.
2. **File > Open Folder** and pick your class folder (where you keep your projects).
3. **Terminal > New Terminal**.
4. Type this and press Enter:

   ```
   git clone https://github.com/Xerrath/overlay-lab-starter.git
   ```

5. **File > Open Folder** and open the new `overlay-lab-starter` folder.
6. Right-click `index.html` and choose **Open with Live Server**.

## Files

- `index.html`: the page. You do not need to change it.
- `global.css`: the styles. Write your code under each `YOUR CODE` comment.
